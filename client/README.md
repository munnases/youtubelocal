# FamilyTube Android client

Architecture for native Kotlin apps on Android phones and Android TV, streaming a small family video library from a home server over Wi-Fi.

Read [the architecture design](ARCHITECTURE.md) for the module structure, phone and TV experience, playback lifecycle, caching and preloading strategy, existing backend integration, and delivery plan.

This directory currently contains the design, not a runnable Android app. The Gradle modules described in the design are proposed implementation structure.
